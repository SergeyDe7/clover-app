CLOVER — СЕРВЕРНЫЙ ЭТАП С ПЕРСОНАЛЬНЫМИ МАТРИЦАМИ И ЦЕНАМИ

Что включено:
- настоящая регистрация клиентов;
- вход по почте и паролю;
- отдельные роли клиента и менеджера;
- защищённое хранение паролей;
- серверная база SQLite;
- профили, адреса, заказы, товары и настройки;
- доступ к данным с разных устройств;
- автоматическое обновление данных каждые 15 секунд;
- автоматический перенос данных из прежней локальной версии;
- постоянные внутренние ID клиентов;
- подготовка связи с контрагентами и номенклатурой 1С;
- персональная товарная матрица каждого клиента;
- клиент по умолчанию видит только закреплённые товары;
- режим «матрица подготавливается» для нового клиента;
- заполнение матрицы по истории заказов;
- разрешение или запрет просмотра полного каталога;
- персональные цены отдельно за штуку, упаковку и пачку;
- источник цены: вручную, по договору или из 1С;
- сервер фильтрует каталог и применяет цены до отправки данных клиенту;
- цена сохраняется внутри оформленного заказа и не меняется задним числом;
- товар вне матрицы можно запросить менеджеру.

ТРЕБОВАНИЯ

Нужен Node.js 22.13 или новее.
Рекомендуется Node.js 22 LTS или 24 LTS.

УСТАНОВКА

1. Остановите старый локальный сайт клавишами Ctrl + C в терминале.

2. Скопируйте всё содержимое архива в:
   C:\Users\Lenovo\Desktop\Clover\clover-app

3. Подтвердите замену файлов.

4. Один раз запустите:
   INSTALL_SERVER.bat

5. После установки запускайте:
   START_CLOVER.bat

6. Откройте:
   http://localhost:5173/

ВХОД МЕНЕДЖЕРА

Почта:
manager@clover.local

Пароль:
Clover123!

КАК НАСТРОИТЬ МАТРИЦУ КЛИЕНТА

1. Клиент регистрируется.
2. Менеджер входит в свой кабинет.
3. Открывает:
   Клиенты → нужный клиент → Товарная матрица, цены и связь с 1С.
4. Выбирает режим:
   - Матрица подготавливается;
   - Только выбранные товары;
   - Все активные товары.
5. Отмечает постоянные позиции.
6. При необходимости указывает персональные цены за:
   - штуку;
   - упаковку;
   - пачку.
7. Выбирает источник цены.
8. Решает, разрешать ли клиенту кнопку «Весь каталог».

Изменения сохраняются автоматически. Клиент увидит их после обновления страницы
или автоматически не позднее чем через 15 секунд.

КАК РАБОТАЕТ ЦЕНА

Приоритет:
1. Персональная цена клиента.
2. Базовая цена товара.
3. «Цена уточняется».

Позже второй уровень будет заменён или дополнен ценой по договору / типу цен из 1С.

ВАЖНО

Это локальная серверная версия для разработки.
База находится здесь:
server\data\clover.sqlite

Перед реальными клиентами:
- перенесём сервер в российский дата-центр;
- заменим SQLite на PostgreSQL;
- включим HTTPS;
- поменяем тестовый пароль менеджера;
- настроим резервные копии;
- добавим фотографии;
- подключим автоматический обмен с 1С.

ДОСТУП С ТЕЛЕФОНА В ОДНОЙ WI-FI СЕТИ

1. В Windows выполните:
   ipconfig

2. Найдите IPv4-адрес компьютера, например:
   192.168.1.25

3. На телефоне откройте:
   http://192.168.1.25:5173/

Компьютер и телефон должны быть в одной Wi-Fi сети.
Разрешите Node.js доступ для частных сетей, если Windows покажет окно брандмауэра.
