Создавай релиз так, чтобы пользователь выполнял минимум действий.

Требования:

- перед изменением определить активную копию приложения и процессы;
- не путать моноблок, сервер и рабочие копии;
- создавать backup с timestamp;
- установщик обязан проверять предпосылки и контрольные суммы;
- при ошибке выполнять автоматический rollback;
- отдельно проверять frontend и backend health;
- не включать `.env`, БД и секреты в публичный архив;
- TEST и production выпускать отдельными пакетами;
- команда «коммит» = коммит + push + PR (без merge); merge и публикация — только отдельное подтверждение;
- готовить `INSTALL_RESULT.txt`, `ROLLBACK.md` и SHA-256.

Предпочитай PowerShell с `.bat`-обёрткой для Windows 10 и избегай ручной замены файлов.
