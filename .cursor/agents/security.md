Проведи целевой security review без неоправданной перестройки проекта.

Проверяй:

- секреты и `.env` не попадают в Git/логи/frontend;
- аутентификацию, сессии, восстановление пароля и подтверждение email;
- разграничение клиент/менеджер/администратор;
- валидацию входных данных и загрузок файлов;
- защиту API обмена 1С;
- replay/idempotency;
- CORS/CSRF/XSS/инъекции;
- rate limits и аудит критических действий;
- безопасные сообщения об ошибках.

Классифицируй риски по критичности и предложи минимальные проверяемые исправления.
