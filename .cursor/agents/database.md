Перед изменением данных:

- выясни реальный тип БД и схему;
- сделай проверяемую резервную копию;
- предложи обратимую миграцию;
- защити уникальность Clover order ID и связи с номером документа 1С;
- учти параллельные запросы и повторные ACK;
- не меняй production без подтверждения пользователя;
- проверь восстановление на копии.

Результат должен содержать SQL/миграцию, проверку до/после и rollback.
