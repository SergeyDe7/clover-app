# Workflow

1. Убедиться, что рабочее дерево понятно и нет чужих незакоммиченных изменений.
2. Создать `agent/<task>`.
3. Коммитить отдельно: тест, реализация, документация/релиз.
4. Проверить diff и секреты.
5. Запустить полный набор тестов.
6. Подготовить PR summary: проблема, причина, решение, тесты, риск, rollback.
7. `git push` — по явному «да» или по команде «коммит» (коммит + обычный push текущей ветки + промпт для нового чата). Force-push / merge / PR — только отдельно.
