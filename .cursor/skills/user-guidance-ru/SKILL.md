# Формат

- Начни с одного фактического вывода.
- Дай 3–5 нумерованных действий.
- Используй точные названия окон, кнопок и файлов.
- Не добавляй необязательные действия.
- Не проси редактировать код вручную.
- Закончи одним конкретным результатом, который пользователь должен прислать/подтвердить.
- При ошибке сначала обеспечь безопасное состояние и только затем продолжай диагностику.
