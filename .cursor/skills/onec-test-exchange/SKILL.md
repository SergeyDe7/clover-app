# Предусловия

- Фактически подтверждена база TEST.
- Сделаны backup backend, данных и расширения 1С.
- Production недоступен тестовому ключу.
- Есть один уникальный тестовый Clover order ID.

# Проверка

1. Health frontend и backend.
2. Очередь содержит ровно нужный заказ.
3. Получение заказа выполнить один раз.
4. Зафиксировать созданный номер документа 1С.
5. Проверить покупателя, 2+ строки по сценарию, количества, цены, сумму, комментарий и Clover ID.
6. Проверить ACK в Clover.
7. Убедиться, что заказ ушёл из очереди только после ACK.
8. Повторный запрос не должен создать новый документ.
9. Чужой номер документа должен быть отклонён.
10. Сохранить доказательства и восстановить тестовые данные при необходимости.

Нельзя повторно нажимать кнопку обмена без анализа результата предыдущего запроса.
