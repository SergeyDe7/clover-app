ФРАГМЕНТЫ ДЛЯ Clover_ОбменКлиент (вставка в конфигураторе)
Имена метаданных типичны для УНФ 1.6 — при ошибке запроса сверьте в конфигураторе:
  Справочник.ДоговорыКонтрагентов / реквизит ВидЦен
  РегистрСведений.ЦеныНоменклатуры

------------------------------------------------------------------------------
A) В выгрузке контрагентов — добавить вид цен с договора
------------------------------------------------------------------------------
Идея: для каждого контрагента найти «основной» договор (не помечен на удаление)
и взять Договор.ВидЦен.

Пример полей элемента JSON (добавить к существующей структуре):

  Элемент.Вставить("priceTypeId", "");
  Элемент.Вставить("priceTypeName", "");
  Элемент.Вставить("priceTypeCode", "");

  // Если у контрагента заполнен договор по умолчанию:
  //   Контрагент.ДоговорПоУмолчанию.ВидЦен
  // Иначе — первый действующий договор владельца.

Пример запроса (уточнить имена в вашей УНФ):

  ВЫБРАТЬ
    Контрагенты.Ссылка КАК Контрагент,
    Контрагенты.Код КАК Код,
    Контрагенты.Наименование КАК Наименование,
    Договоры.ВидЦен КАК ВидЦен
  ИЗ
    Справочник.Контрагенты КАК Контрагенты
      ЛЕВОЕ СОЕДИНЕНИЕ Справочник.ДоговорыКонтрагентов КАК Договоры
      ПО Договоры.Владелец = Контрагенты.Ссылка
        И НЕ Договоры.ПометкаУдаления
  ГДЕ
    НЕ Контрагенты.ПометкаУдаления

В цикле:

  Если ЗначениеЗаполнено(Результат.ВидЦен) Тогда
    Элемент.Вставить("priceTypeId", Строка(Результат.ВидЦен.УникальныйИдентификатор()));
    Элемент.Вставить("priceTypeName", Строка(Результат.ВидЦен));
    Попытка
      Элемент.Вставить("priceTypeCode", Результат.ВидЦен.Код);
    Исключение
    КонецПопытки;
  КонецЕсли;

Тот же POST /api/one-c/clients-preview, что уже есть.


------------------------------------------------------------------------------
B) Выгрузка справочника видов цен
------------------------------------------------------------------------------
Функция ОтправитьВидыЦенВClover() Экспорт
  // HTTP POST на {CloverURL}/api/one-c/price-types
  // Заголовки: X-Clover-Key, X-Clover-Database: TEST, Content-Type: application/json
  // Тело:
  // { "items": [ { "id": "...", "code": "...", "name": "Оптовая" }, ... ] }

  ТекстЗапроса =
  "ВЫБРАТЬ
  |  ВидыЦен.Ссылка КАК Ссылка,
  |  ВидыЦен.Код КАК Код,
  |  ВидыЦен.Наименование КАК Наименование
  |ИЗ
  |  Справочник.ВидыЦен КАК ВидыЦен
  |ГДЕ
  |  НЕ ВидыЦен.ПометкаУдаления
  |УПОРЯДОЧИТЬ ПО
  |  ВидыЦен.Наименование";

  // ... собрать items и HTTPЗапрос как в ОтправитьКонтрагентыПредпросмотр
КонецФункции

Имя справочника в УНФ может быть «ВидыЦен» или «ВидыЦенНоменклатуры» — проверьте дерево.

  // 1) GET  {CloverURL}/api/one-c/sale-price-request

  // }

  // РегистрСведений.ЦеныНоменклатуры.СрезПоследних(, )
