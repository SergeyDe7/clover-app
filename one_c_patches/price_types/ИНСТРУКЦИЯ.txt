================================================================================
ВИД ЦЕН КЛИЕНТА + АВТООБНОВЛЕНИЕ ЦЕН МАТРИЦЫ В CLOVER
База: только КОПИЯ / TEST. Production не трогаем.
================================================================================

ЦЕЛЬ
----
1) В 1С: карточка контрагента → вкладка «Договоры» → в договоре поле «Вид цен».
2) При выгрузке контрагентов в Clover у связанного клиента появляется эта категория.
3) При выгрузке продажных цен по виду — цены в матрице клиента Clover меняются онлайн
   (тихий bootstrap ~5 сек, как статусы заказов).


ЧТО УЖЕ ЕСТЬ В CLOVER (сервер ДЦ)
--------------------------------
- POST /api/one-c/clients-preview  — принимает priceTypeId / priceTypeName у контрагента
- POST /api/one-c/price-types      — справочник видов цен
- GET  /api/one-c/sale-price-request — какие цены нужны
- POST /api/one-c/sale-prices      — продажные цены по виду
- Онлайн-обновление витрины клиента


ЧТО СДЕЛАТЬ В 1С (расширение CloverExchange)
--------------------------------------------
Модуль: Общие → Общие модули → Clover_ОбменКлиент

1) В функции выгрузки контрагентов (ОтправитьКонтрагентыПредпросмотр)
   для каждого контрагента добавить поля из ОСНОВНОГО договора:
     priceTypeId, priceTypeName, priceTypeCode
   Образец запроса и JSON — в ФРАГМЕНТЫ_BSL.txt

2) Добавить (или кнопку меню) выгрузку видов цен:
     ОтправитьВидыЦенВClover → POST /api/one-c/price-types

3) Добавить выгрузку продажных цен по виду:
     ОтправитьПродажныеЦеныВClover →
       GET  /api/one-c/sale-price-request
       POST /api/one-c/sale-prices
   Цены брать из регистра сведений ЦеныНоменклатуры (срез последних).

4) Конфигурация → Обновить конфигурацию БД.


ПОРЯДОК ПРОВЕРКИ
----------------
1. 1С TEST: Восточная Лавка → Договоры → открыть договор → «Вид цен» = нужный.
2. Раздел Clover → «Отправить контрагентов в Clover - тест».
3. Clover: Клиенты → карточка → поле «Категория цен 1С» заполнилось.
4. Раздел Clover → выгрузка продажных цен (новая кнопка / команда).
5. Изменить цену товара этого вида в 1С → снова выгрузить продажные цены.
6. В ЛК клиента Clover (Ctrl+Shift+R или подождать ~5 сек) цена в матрице обновилась.


ЕСЛИ В ДОГОВОРЕ НЕТ ПОЛЯ «Вид цен»
----------------------------------
В УНФ 1.6 оно почти всегда есть в форме договора.
Если поля нет — пришлите скрин формы договора, подстроим имя реквизита
(иногда ВидЦенНоменклатуры / ТипЦен).
