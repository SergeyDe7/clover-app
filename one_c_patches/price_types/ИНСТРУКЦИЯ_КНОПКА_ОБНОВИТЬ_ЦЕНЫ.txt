КНОПКА «Обновить цены» (1С TEST) — вариант 1 без регламента
============================================================

Оставляем ручную выгрузку. Отдельная кнопка только для цен
(после смены цены в регистре 1С) — быстрее, чем «контрагенты и цены».


ЧТО УЖЕ ЕСТЬ
------------
В модуле Clover_ОбменКлиент должна быть функция:
  ОтправитьПродажныеЦеныВClover() Экспорт
(она уже в вашем полном модуле).


ДОБАВИТЬ КНОПКУ
---------------
1. Конфигуратор → расширение CloverExchange → Общие → Общие команды.

2. Правой кнопкой по команде «Отправить контрагентов…»
   → скопировать (или создать новую по её образцу).

3. У новой команды:
   Имя (латиница):     Clover_ОбновитьЦены
   Синоним (в меню):   Обновить цены в Clover - тест

4. Группа / подсистема — та же, где кнопки Clover
   (Панель действий.Сервис / раздел Clover).

5. Модуль команды → заменить ОбработкаКоманды целиком из файла:
   КОМАНДА_ОБНОВИТЬ_ЦЕНЫ_ОБРАЗЕЦ.txt

6. Конфигурация → Обновить конфигурацию базы данных.

7. 1С:Предприятие → меню Clover → «Обновить цены в Clover - тест».


КАК ПОЛЬЗОВАТЬСЯ
----------------
• Сменили цену в 1С по виду цен клиента
  → нажать «Обновить цены».
• Сообщение: «Цены обновлены в Clover: N» (N > 0).
• В ЛК клиента через ~5 сек цена сама обновится.

«Отправить контрагентов и цены» — когда нужны ещё контрагенты /
категории (виды цен). Для одной смены цены достаточно «Обновить цены».


НЕ НУЖНО
--------
Регламентное задание не создаём (вариант 2 отложен).
Прод не трогаем без отдельного «да».
