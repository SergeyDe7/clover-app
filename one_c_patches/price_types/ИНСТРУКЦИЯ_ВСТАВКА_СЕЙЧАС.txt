================================================================================
ВСТАВКА В 1С TEST — виды цен + продажные цены → Clover
Среда: только КОПИЯ / TEST. VLAVKA / production — НЕ трогать.
================================================================================

С ДЦ конфигуратор открыть нельзя — делаете на компе1 (где 1С TEST).


ЧАСТЬ 1. Ключ в новый блок
--------------------------
1. 1С → база TEST → «Конфигуратор».
2. «Конфигурация» → «Расширения конфигурации» → дважды «CloverExchange».
3. Слева: «Общие» → «Общие модули» → «Clover_ОбменКлиент».
4. Ctrl+F → найдите `X-Clover-Key` (в ОтправитьКонтрагентыПредпросмотр).
5. Скопируйте значение ключа (в чат НЕ присылать).
6. Откройте файл:
   one_c_patches/price_types/ВСТАВИТЬ_В_КОНЕЦ_МОДУЛЯ.txt
7. В функции Clover_КлючОбменаAPI() вставьте ключ:
   Возврат "…ваш ключ…";
8. Проверьте Clover_ХостAPI() = 192.168.155.15 и порт 4100
   (как после смены URL на ДЦ).


ЧАСТЬ 2. Вставить код в конец модуля
------------------------------------
1. В модуле Clover_ОбменКлиент: Ctrl+End (в самый конец).
2. Откройте ВСТАВИТЬ_В_КОНЕЦ_МОДУЛЯ.txt в Блокноте → Ctrl+A → Ctrl+C.
3. В модуле 1С: Ctrl+V.
4. Ctrl+S.


ЧАСТЬ 3. Вид цен при выгрузке контрагентов (обязательно)
--------------------------------------------------------
В той же функции ОтправитьКонтрагентыПредпросмотр найдите место, где
собирается Элемент (после Вставить "name" / "code") и ДОБАВЬТЕ:

	ВидЦенДанные = Clover_ВидЦенИзДоговора(Результат.Ссылка);
	Элемент.Вставить("priceTypeId", ВидЦенДанные.id);
	Элемент.Вставить("priceTypeName", ВидЦенДанные.name);
	Элемент.Вставить("priceTypeCode", ВидЦенДанные.code);

Если переменная ссылки называется иначе (не Результат.Ссылка) —
подставьте вашу переменную контрагента.

Ctrl+S.


ЧАСТЬ 4. Кнопки меню (раздел Clover)
------------------------------------
Как для «Отправить контрагентов…» (см. ИНСТРУКЦИЯ_КНОПКА_КОНТРАГЕНТЫ.txt):

Кнопка A:
  Синоним: Отправить виды цен в Clover - тест
  Обработчик (клиент!):

	Результат = Clover_ОбменКлиент.ОтправитьВидыЦенВClover();
	Сообщить("Виды цен: код " + Результат.КодСостояния
		+ ", шт. " + Результат.Количество);

Кнопка B:
  Синоним: Отправить продажные цены в Clover - тест
  Обработчик:

	Результат = Clover_ОбменКлиент.ОтправитьПродажныеЦеныВClover();
	Сообщить("Продажные цены: код " + Результат.КодСостояния
		+ ", шт. " + Результат.Количество);

Образец команды контрагентов: one_c_patches/empty_queue_and_comment/КОМАНДА_КОНТРАГЕНТЫ_ОБРАЗЕЦ.txt
(важно: &НаКлиенте, не сервер — иначе HTTP блокируется).


ЧАСТЬ 5. Обновить БД
--------------------
«Конфигурация» → «Обновить конфигурацию базы данных» → «Да» / «Принять».
Закрыть конфигуратор → открыть «1С:Предприятие» (TEST).


ЧАСТЬ 6. Проверка
-----------------
1. Контрагент → Договоры → вид цен задан → Записать.
2. Clover → «Отправить виды цен в Clover - тест».
3. Clover → «Отправить контрагентов в Clover - тест».
4. В Clover (менеджер): Клиенты → карточка → «Категория цен 1С» заполнилась.
5. «Отправить продажные цены в Clover - тест».
   Сообщение: «переданы: N; пропущено нулевых: M» (нули в регистре по-прежнему
   не шлём — by design; M = счётчик ПропущеноНулей).
6. Сменить цену товара этого вида в 1С → снова п.5.
7. ЛК клиента Clover: Ctrl+Shift+R (или ~5 сек) — цена в матрице обновилась.

Если функция ОтправитьПродажныеЦеныВClover уже есть в модуле — замените её
целиком из ВСТАВИТЬ_В_КОНЕЦ_МОДУЛЯ.txt (блок с ПропущеноНулей) и обновите
текст команды из КОМАНДА_ПРОДАЖНЫЕ_ЦЕНЫ_ОБРАЗЕЦ.txt.


Если запрос падает на «ДоговорыКонтрагентов» / «ВидыЦен» / «ЦеныНоменклатуры»
-----------------------------------------------------------------------------
Пришлите текст ошибки из 1С — подстроим имена метаданных под вашу УНФ.
Или выгрузите модуль в .txt БЕЗ ключа (замените ключ на ***) и пришлите —
доточим функции под ваш код.
