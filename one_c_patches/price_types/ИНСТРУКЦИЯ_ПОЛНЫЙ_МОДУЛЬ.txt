ПОЛНЫЙ МОДУЛЬ Clover_ОбменКлиент (виды цен + продажные цены)
============================================================

Файл: ПОЛНЫЙ_МОДУЛЬ_вставить_целиком.txt

**Контур: TEST-only.** В модуле `X-Clover-Database` и JSON
`body.database` (purchase-prices) = **TEST**. Не вставляйте этот файл
в VLAVKA as-is — получите header/body conflict или чужой контур.
Для VLAVKA используйте `one_c_patches/vlavka/ПОЛНЫЙ_МОДУЛЬ_VLAVKA.txt`.

Это ваш текущий модуль с моноблока + доработки:
  • в ОтправитьКонтрагентыПредпросмотр — priceTypeId/Name/Code с договора
  • после выгрузки клиентов — ОтправитьВидыЦенВClover()
  • новые: Clover_ВидЦенИзДоговора, ОтправитьВидыЦенВClover,
            ОтправитьПродажныеЦеныВClover

НА МОНОБЛОКЕ (1С TEST, не прод!):
1. Откройте общий модуль Clover_ОбменКлиент.
2. Выделите ВЕСЬ текст модуля → Delete.
3. Откройте ПОЛНЫЙ_МОДУЛЬ_вставить_целиком.txt в Блокноте (UTF-8).
4. Ctrl+A → Ctrl+C → вставьте в модуль 1С.
5. Сохраните, обновите конфигурацию БД.

ПРОВЕРКА:
1. Вызовите ОтправитьКонтрагентыПредпросмотр() — HTTP 200,
   у связанных клиентов в Clover появится вид цен с договора.
2. (опционально) кнопка/вызов ОтправитьВидыЦенВClover().
3. (опционально) кнопка/вызов ОтправитьПродажныеЦеныВClover() —
   подтянет цены матрицы по назначенным видам цен.
   Образцы команд: КОМАНДА_*_ОБРАЗЕЦ.txt

БЕЗОПАСНОСТЬ:
Ключ в git/чатах не хранить. Для TEST — отдельный
`ONEC_TEST_EXCHANGE_API_KEY`, не shared с VLAVKA.

Не вставляйте этот файл в прод / VLAVKA без отдельного «да» и
переписывания контура header+body на VLAVKA.
