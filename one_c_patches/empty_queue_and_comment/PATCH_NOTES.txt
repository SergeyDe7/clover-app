# Готовый файл: Clover_module.bsl / Clover_module_для_вставки.txt

По шаблону формы заказа (поле «Отгрузка» под «Договор»):

1) Пустая очередь → «Нет новых заказов»
2) Комментарий → только «Заказ Clover № CL-...»
3) Шапка (орг., вид цен, склад, НДС) → образец №3265
4) Состояние → «В обработке» с образца №3266 (не «Обработан» с 3265)
5) Единицы → всегда «шт»
6) Дата отгрузки → только реквизит шапки «Отгрузка»/«ДатаОтгрузки»
   В строки табличной части дату НЕ записываем
