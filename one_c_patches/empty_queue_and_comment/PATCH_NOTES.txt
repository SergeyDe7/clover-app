# Готовый файл: Clover_module.bsl / Clover_module_для_вставки.txt

По шаблону формы заказа (поле «Отгрузка» под «Договор»):

1) Пустая очередь → «Нет новых заказов»
2) Комментарий → только «Заказ Clover № CL-...»
3) Шапка (орг., вид цен, склад, НДС) → образец №3265
4) Состояние при создании из Clover → пустое (не «В обработке», не «Обработан»)
5) Единицы → всегда «шт»
6) Дата отгрузки → только реквизит шапки «Отгрузка»/«ДатаОтгрузки»
   В строки табличной части дату НЕ записываем
7) ОтправитьКонтрагентыПредпросмотр → полная выгрузка контрагентов
   в Clover (POST /api/one-c/clients-preview). Кнопка меню:
   см. ИНСТРУКЦИЯ_КНОПКА_КОНТРАГЕНТЫ.txt
8) Ручная смена СостояниеЗаказа в документе Clover → POST
   /api/one-c/orders/accepted → у клиента статус «Принят».
   Подписки ПередЗаписью/ПриЗаписи: см. ИНСТРУКЦИЯ_СТАТУС_ПРИНЯТ.txt
9) СоздатьТестовыйЗаказ() — один клик кнопки принимает всю очередь
   (внутри цикл СоздатьОдинТестовыйЗаказ → claim→документ→ACK, лимит 100).
   Менять обработчик кнопки не обязательно.
   см. ИНСТРУКЦИЯ_ПРИНЯТЬ_ВСЕ.txt
