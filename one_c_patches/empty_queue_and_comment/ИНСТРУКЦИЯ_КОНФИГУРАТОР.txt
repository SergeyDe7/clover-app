================================================================================
CLOVER → 1С TEST: правка расширения
Только база КОПИЯ / TEST. Не VLAVKA.
Папка: clover-app\one_c_patches\empty_queue_and_comment\
================================================================================

ВАЖНО: имя файла модуля сохраняйте ЛАТИНИЦЕЙ:
  Clover_module.bsl
(не используйте русские буквы в имени файла — из-за них ломается .bat)


------------------------------------------------------------------------------
ЧАСТЬ A. Открыть конфигуратор
------------------------------------------------------------------------------

1. Закройте обычное окно 1С, если мешает.
2. Откройте «1С:Предприятие».
3. Выберите базу КОПИЯ / TEST (не VLAVKA).
4. Справа нажмите «Конфигуратор».
5. Дождитесь открытия.


------------------------------------------------------------------------------
ЧАСТЬ B. Открыть расширение CloverExchange
------------------------------------------------------------------------------

1. Меню «Конфигурация».
2. Если слева нет дерева: «Конфигурация» → «Открыть конфигурацию».
3. «Конфигурация» → «Расширения конфигурации».
4. Найдите «CloverExchange» → откройте двойным щелчком.


------------------------------------------------------------------------------
ЧАСТЬ C. Модуль Clover_ОбменКлиент
------------------------------------------------------------------------------

1. В дереве: «Общие» → «Общие модули».
2. Модуль: Clover_ОбменКлиент.
3. Дважды щёлкните — откроется текст.


------------------------------------------------------------------------------
ЧАСТЬ D. Выгрузить модуль в файл (латинское имя!)
------------------------------------------------------------------------------

Самый надёжный способ:

1. В окне модуля: Ctrl+A → Ctrl+C.
2. Откройте Блокнот Windows.
3. Ctrl+V.
4. «Файл» → «Сохранить как».
5. Папка:

   C:\Users\Lonovo\Desktop\Clover\clover-app\one_c_patches\empty_queue_and_comment\

6. «Тип файла» = «Все файлы».
7. Имя файла ТОЧНО (латиницей):

   Clover_module.bsl

8. Кодировка: UTF-8 (если есть выбор).
9. Сохранить.


------------------------------------------------------------------------------
ЧАСТЬ E. Применить патч
------------------------------------------------------------------------------

1. Откройте ту же папку в Проводнике.
2. Дважды щёлкните файл:

   APPLY_PATCH.bat

3. В чёрном окне должно быть:
   Using module: ...\Clover_module.bsl
   OK. Patched: ...

4. Если ERROR: module file not found — вернитесь к части D
   и сохраните именно Clover_module.bsl в эту папку.

5. Если WARNING: no automatic replacements matched —
   пришлите файл Clover_module.bsl в чат (@dsd).


------------------------------------------------------------------------------
ЧАСТЬ F. Загрузить обратно в 1С
------------------------------------------------------------------------------

1. Конфигуратор, модуль Clover_ОбменКлиент.
2. Ctrl+A → Delete.
3. Откройте в Блокноте исправленный Clover_module.bsl.
4. Ctrl+A → Ctrl+C.
5. В модуле 1С: Ctrl+V.
6. Ctrl+S (сохранить).


------------------------------------------------------------------------------
ЧАСТЬ G. Обновить базу
------------------------------------------------------------------------------

1. «Конфигурация» → «Обновить конфигурацию базы данных».
2. Подтвердите.
3. Закройте конфигуратор.
4. Откройте ту же базу как «1С:Предприятие».


------------------------------------------------------------------------------
ЧАСТЬ H. Проверка
------------------------------------------------------------------------------

1. Пустая очередь → получение заказа → сообщение: «Нет новых заказов».
2. Новый заказ Clover → в комментарии документа только:
   Заказ Clover № CL-...
   (без [CLOVER:...] и «Адрес доставки»).


------------------------------------------------------------------------------
ОТКАТ
------------------------------------------------------------------------------

Рядом появится файл Clover_module.bsl.bak-...
Скопируйте его поверх Clover_module.bsl и повторите части F–G.
