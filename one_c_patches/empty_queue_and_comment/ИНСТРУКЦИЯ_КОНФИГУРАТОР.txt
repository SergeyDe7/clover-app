================================================================================
CLOVER → 1С TEST: правка расширения БЕЗ ручного копирования кода из чата
Только база КОПИЯ / TEST. Не VLAVKA.
Папка: clover-app\one_c_patches\empty_queue_and_comment\
================================================================================

ИТОГ: вы выгружаете модуль в файл → запускаете Apply-Patch.ps1 → загружаете
файл обратно в конфигуратор. Код из чата руками не вставляете.


------------------------------------------------------------------------------
ЧАСТЬ A. Открыть конфигуратор нужной базы
------------------------------------------------------------------------------

1. Закройте обычное окно 1С (тонкий/толстый клиент), если оно мешает.
2. Откройте «1С:Предприятие».
3. В списке баз выберите базу с пометкой КОПИЯ / TEST (не VLAVKA).
4. Справа нажмите кнопку «Конфигуратор» (не «1С:Предприятие»).
5. Дождитесь открытия конфигуратора.


------------------------------------------------------------------------------
ЧАСТЬ B. Открыть расширение CloverExchange
------------------------------------------------------------------------------

1. Вверху меню: «Конфигурация».
2. Если слева нет дерева конфигурации: «Конфигурация» → «Открыть конфигурацию».
3. Меню «Конфигурация» → «Расширения конфигурации».
4. В списке расширений найдите «CloverExchange» (или похожее имя Clover).
5. Откройте его двойным щелчком (или «Изменить»).


------------------------------------------------------------------------------
ЧАСТЬ C. Найти модуль Clover_ОбменКлиент
------------------------------------------------------------------------------

1. В дереве расширения раскройте ветку «Общие» → «Общие модули»
   (иногда просто «Общие модули»).
2. Найдите модуль с именем: Clover_ОбменКлиент
   (в ошибке было: ОбщийМодуль.Clover_ОбменКлиент).
3. Дважды щёлкните по модулю — откроется текст на языке 1С.


------------------------------------------------------------------------------
ЧАСТЬ D. Выгрузить модуль в файл (чтобы скрипт сам правил)
------------------------------------------------------------------------------

Вариант 1 (если есть пункт меню):
1. Курсор внутри текста модуля.
2. Меню «Файл» → «Сохранить как...» / «Сохранить копию...»
3. Тип файла: текстовый файл.
4. Сохраните сюда (создайте папку, если нужно):

   C:\Users\Lonovo\Desktop\Clover\clover-app\one_c_patches\empty_queue_and_comment\Clover_ОбменКлиент.bsl

Вариант 2 (если «Сохранить как» нет):
1. В окне модуля нажмите Ctrl+A (выделить всё).
2. Ctrl+C (копировать).
3. Откройте Блокнот Windows.
4. Ctrl+V.
5. «Файл» → «Сохранить как».
6. «Тип файла» = «Все файлы».
7. Имя файла точно:

   Clover_ОбменКлиент.bsl

8. Кодировка: UTF-8 (если спрашивает).
9. Папка:

   C:\Users\Lonovo\Desktop\Clover\clover-app\one_c_patches\empty_queue_and_comment\


------------------------------------------------------------------------------
ЧАСТЬ E. Применить патч скриптом (без ручной вставки кода)
------------------------------------------------------------------------------

1. Откройте Проводник Windows.
2. Перейдите в папку:

   C:\Users\Lonovo\Desktop\Clover\clover-app\one_c_patches\empty_queue_and_comment\

3. В адресной строке проводника введите: powershell
   и нажмите Enter (откроется PowerShell в этой папке).

4. Выполните одну команду:

powershell -ExecutionPolicy Bypass -File .\Apply-Patch.ps1 -ModuleFile ".\Clover_ОбменКлиент.bsl"

5. Должно появиться: OK. Патч применён...
   Рядом создастся файл .bak-... (резервная копия до правки).

Если скрипт напишет «автоматические замены не сработали»:
- не загружайте файл обратно;
- пришлите в чат файл Clover_ОбменКлиент.bsl (или скрин текста около
  «Товары переданы» и «CLOVER») — подготовлю точный патч под ваш модуль.


------------------------------------------------------------------------------
ЧАСТЬ F. Загрузить исправленный файл обратно в модуль
------------------------------------------------------------------------------

1. Вернитесь в конфигуратор, окно модуля Clover_ОбменКлиент.
2. Выделите весь старый текст: Ctrl+A → Delete.
3. Откройте в Блокноте уже исправленный файл:

   C:\Users\Lonovo\Desktop\Clover\clover-app\one_c_patches\empty_queue_and_comment\Clover_ОбменКлиент.bsl

4. Ctrl+A → Ctrl+C в Блокноте.
5. В окне модуля 1С: Ctrl+V.
6. Сохраните модуль: Ctrl+S (или дискета / «Файл» → «Сохранить»).

(Если в вашей версии 1С есть «Загрузить из файла» для модуля — используйте его
вместо Delete/Paste: это ещё проще.)


------------------------------------------------------------------------------
ЧАСТЬ G. Применить изменения к базе
------------------------------------------------------------------------------

1. Меню «Конфигурация» → «Обновить конфигурацию базы данных»
   (или кнопка F7 / «Обновить конфигурацию БД» — как у вас подписано).
2. Подтвердите обновление (Да / Принять).
3. Дождитесь окончания без ошибок.
4. Закройте конфигуратор.
5. Откройте эту же базу КОПИЯ уже как «1С:Предприятие» (обычная работа).


------------------------------------------------------------------------------
ЧАСТЬ H. Проверка
------------------------------------------------------------------------------

1. В Clover очередь пустая.
2. В 1С нажмите получение заказа Clover.
3. Ожидаемое сообщение: «Нет новых заказов»
   (без длинного HTTP/JSON и пути модуля — если патч нашёл нужные строки).

4. Создайте новый тестовый заказ в Clover → передайте в очередь → получите в 1С.
5. В комментарии документа должно остаться только:
   Заказ Clover № CL-...
   без строк [CLOVER:...] и «Адрес доставки».


------------------------------------------------------------------------------
ОТКАТ
------------------------------------------------------------------------------

1. Возьмите файл *.bak-... рядом с модулем.
2. Скопируйте его поверх Clover_ОбменКлиент.bsl
3. Повторите ЧАСТЬ F и G.
