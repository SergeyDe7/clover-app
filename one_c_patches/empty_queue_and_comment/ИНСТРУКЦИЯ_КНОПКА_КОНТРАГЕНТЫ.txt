КНОПКА: «Отправить контрагентов в Clover - тест» (только база КОПИЯ/TEST)
================================================================================

Нужно два шага: (A) обновить модуль Clover_ОбменКлиент, (B) добавить команду
в меню Clover по образцу кнопки товаров.

Файл модуля (уже с функцией ОтправитьКонтрагентыПредпросмотр):

  C:\Users\Lonovo\Desktop\Clover\clover-app\one_c_patches\empty_queue_and_comment\Clover_module_для_вставки.txt

  (то же содержимое: Clover_module.bsl)


------------------------------------------------------------------------------
A. ВСТАВИТЬ АКТУАЛЬНЫЙ МОДУЛЬ
------------------------------------------------------------------------------

1. 1С → база КОПИЯ/TEST → «Конфигуратор».

2. «Конфигурация» → «Расширения конфигурации» → «CloverExchange».

3. «Общие» → «Общие модули» → «Clover_ОбменКлиент» (двойной щелчок).

4. В модуле: Ctrl+A → Delete.

5. Блокнот → открыть Clover_module_для_вставки.txt → Ctrl+A → Ctrl+C.

6. В окно модуля 1С: Ctrl+V → Ctrl+S.

7. Пока НЕ обновляйте БД — сначала сделайте шаг B (кнопку), потом один раз
   «Обновить конфигурацию базы данных».


------------------------------------------------------------------------------
B. ДОБАВИТЬ КОМАНДУ / КНОПКУ В МЕНЮ CLOVER
------------------------------------------------------------------------------

Самый простой и безопасный способ — скопировать уже рабочую команду товаров.

1. В дереве расширения CloverExchange найдите общую команду
   «Отправить товары в Clover - тест»
   (обычно: Общие → Общие команды, либо рядом с подсистемой Clover).

2. Правой кнопкой по этой команде → «Добавить» / «Скопировать»
   (если «Скопировать» нет: создайте новую «Общую команду» и повторите
   настройки с команды товаров 1-в-1).

3. У новой команды задайте:
   - Имя (латиницей), например: Clover_ОтправитьКонтрагенты
   - Синоним: Отправить контрагентов в Clover - тест

4. Откройте модуль команды (или «Командный интерфейс» / обработчик —
   как у кнопки товаров).

5. В обработчике команды товаров найдите вызов вида:

     Clover_ОбменКлиент.ОтправитьТоварыПредпросмотр()

   В НОВОЙ команде замените на:

     Clover_ОбменКлиент.ОтправитьКонтрагентыПредпросмотр()

   Сообщения пользователю по желанию оставьте по образцу товаров, например:
   «Контрагенты переданы в Clover: N» / код HTTP из результата.

6. Подключите команду к подсистеме / разделу «Clover» в командном интерфейсе
   (там же, где видны «Отправить товары…», «Получить тестовый заказ…»).

7. «Конфигурация» → «Обновить конфигурацию базы данных» → «Да» / «Принять».

8. Закройте конфигуратор. Откройте базу как «1С:Предприятие».


------------------------------------------------------------------------------
C. ПРОВЕРКА
------------------------------------------------------------------------------

1. Убедитесь, что Clover API на http://localhost:4100/ (или ваш IP) запущен
   с НОВЫМ кодом (полный каталог контрагентов).

2. В 1С: раздел Clover → «Отправить контрагентов в Clover - тест».

3. Ожидание: сообщение об успехе, код ответа 200, количество > 0.

4. В Clover: Клиенты → клиент → «Выбрать контрагента 1С» → поиск по имени.

Если команда товаров вызывает не модуль, а внешнюю обработку — пришлите
скрин модуля обработчика кнопки товаров, подстроим текст вызова.


Не применяйте это в VLAVKA / production без отдельного «да».
