================================================================================
ПРИНЯТЬ ВСЕ НОВЫЕ ЗАКАЗЫ ИЗ CLOVER ОДНИМ КЛИКОМ (1С TEST)
================================================================================

Цель: кнопка «Получить тестовый заказ из Clover» принимает всю очередь
за один клик (не по одному).

Что в репозитории / локально:
  - Clover_module.bsl / Clover_module_для_вставки.txt — полный модуль
    (локально; *.bsl не в Git из-за ключа API)
  - ВСТАВИТЬ_ФУНКЦИЮ_ПРИНЯТЬ_ВСЕ.txt — краткая памятка
  - КОМАНДА_ПРИНЯТЬ_ВСЕ_ОБРАЗЕЦ.txt — опциональный образец кнопки

Как устроено в модуле:
  - СоздатьТестовыйЗаказ() — вход кнопки; принимает ВСЮ очередь
  - СоздатьОдинТестовыйЗаказ() — один claim → документ → ACK
  - СоздатьВсеТестовыеЗаказы() — цикл (вызывается из СоздатьТестовыйЗаказ)
  - Лимит: 100 заказов за клик

Менять обработчик кнопки НЕ обязательно (кнопка уже зовёт СоздатьТестовыйЗаказ).

Ограничения:
  - Только база TEST / КОПИЯ. Production / VLAVKA — только после явного «да».


------------------------------------------------------------------------------
УСТАНОВКА (полная замена модуля)
------------------------------------------------------------------------------

1. Откройте 1С → база TEST → «Конфигуратор».
2. «Конфигурация» → «Расширения конфигурации» → «CloverExchange».
3. «Общие» → «Общие модули» → «Clover_ОбменКлиент».
4. Ctrl+A → Delete.
5. Вставьте содержимое Clover_module_для_вставки.txt (из Блокнота).
6. Ctrl+S.
7. «Конфигурация» → «Обновить конфигурацию базы данных» → «Да» / «Принять».
8. «1С:Предприятие» → в Clover очередь 2+ заказов → один клик кнопки приёма.

Проверка: в модуле Ctrl+F → «СоздатьОдинТестовыйЗаказ» должен находиться.
Ожидаемо: сообщение с несколькими номерами документов 1С.


Откат: вернуть предыдущий backup модуля из backups\before-onec-accept-all-*
или прежнюю выгрузку Clover_ОбменКлиент.
