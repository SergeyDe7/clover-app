================================================================================
ТЕКСТ ПОСЛЕ ПРИЁМА ЗАКАЗА: «Создан заказ из Clover»
================================================================================

Где менять (на моноблоке, в базе TEST и/или VLAVKA):

1. 1С → нужная база → Конфигуратор.
2. Конфигурация → Расширения конфигурации → CloverExchange.
3. Общие → Общие команды → команда получения заказа
   (синоним может быть «Получить заказ из Clover» / старое «…тестовый…»).
4. Откройте модуль этой команды (двойной щелчок / «Открыть модуль»).
5. Найдите Сообщить(... ) после успешного СоздатьТестовыйЗаказ().
6. Замените текст на образец из КОМАНДА_ПРИНЯТЬ_ВСЕ_ОБРАЗЕЦ.txt
   (главная фраза: «Создан заказ из Clover»).
7. Ctrl+S → Конфигурация → Обновить конфигурацию БД → Принять.
8. 1С:Предприятие → снова получите заказ — должно быть новое сообщение.

Имя процедуры СоздатьТестовыйЗаказ() в модуле Clover_ОбменКлиент НЕ меняйте.
================================================================================
