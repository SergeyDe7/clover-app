ИНСТРУКЦИЯ: обход без «Подписки на события» (кнопка «Добавить» серая)
=====================================================================
Среда: только 1С TEST. Подписки НЕ нужны.

Почему «Добавить» серая
-----------------------
В расширении CloverExchange платформа часто не даёт создавать
«Подписки на события». Это нормально — делаем через форму документа.

Что сделать вместо подписок
---------------------------
A) Обновить модуль Clover_ОбменКлиент (если ещё не обновили после правки
   с СообщитьОПринятииПоРеквизитам) — файл Clover_module.bsl
B) Заимствовать форму «Заказ покупателя» и вставить 10 строк в модуль формы.

------------------------------------------------------------------------------
B1. Заимствовать документ и форму
------------------------------------------------------------------------------
1. Конфигуратор → Расширения → CloverExchange (откройте дерево расширения).

2. Меню «Конфигурация» основной базы (не расширения) → «Открыть конфигурацию»,
   если дерево основной конфигурации не видно.

3. В дереве ОСНОВНОЙ конфигурации найдите:
   Документы → ЗаказПокупателя

4. Правой кнопкой по «ЗаказПокупателя» → «Добавить в расширение»
   (или «Add to extension»). Выберите расширение CloverExchange.
   Если спросит что добавлять — достаточно сам документ.

5. В дереве РАСШИРЕНИЯ CloverExchange раскройте:
   Документы → ЗаказПокупателя → Формы

6. Правой кнопкой по основной форме документа
   (часто «ФормаДокумента» / «DocumentForm») → «Добавить в расширение».

------------------------------------------------------------------------------
B2. Вставить обработчик в модуль формы
------------------------------------------------------------------------------
1. В расширении: Документы → ЗаказПокупателя → Формы → (ваша форма)
   → откройте «Модуль» формы (не модуль объекта).

2. В КОНЕЦ модуля формы вставьте (скопируйте целиком):

&НаКлиенте
&После("ПослеЗаписи")
Процедура Clover_ПослеЗаписи(ПараметрыЗаписи)

	Комментарий = "";
	НомерДокумента = "";
	СостояниеТекст = "";
	Попытка
		Комментарий = Строка(Объект.Комментарий);
		НомерДокумента = Строка(Объект.Номер);
	Исключение
		Возврат;
	КонецПопытки;

	НомерClover = Clover_ОбменКлиент.ИзвлечьНомерЗаказаCloverИзКомментария(
		Комментарий);
	Если НомерClover = "" Тогда
		Возврат;
	КонецЕсли;

	Попытка
		СостояниеТекст = СокрЛП(Строка(Объект.СостояниеЗаказа));
	Исключение
		Попытка
			СостояниеТекст = СокрЛП(Строка(Объект.Состояние));
		Исключение
			СостояниеТекст = "";
		КонецПопытки;
	КонецПопытки;

	Если СостояниеТекст = "" Тогда
		Возврат;
	КонецЕсли;

	Попытка
		Clover_ОбменКлиент.СообщитьОПринятииПоРеквизитам(
			НомерClover,
			НомерДокумента,
			СостояниеТекст);
	Исключение
		Сообщить("Clover: не удалось обновить статус клиента. "
			+ ОписаниеОшибки());
	КонецПопытки;

КонецПроцедуры

3. Ctrl+S.

4. Конфигурация → Обновить конфигурацию базы данных → Да / Принять.

5. Закройте конфигуратор.

------------------------------------------------------------------------------
Проверка
------------------------------------------------------------------------------
1. Новый заказ Clover → в 1С: состояние пустое.
2. В форме заказа вручную выберите любое состояние → Записать.
3. В Clover у клиента статус: Принят.

Если при записи ошибка про «СостояниеЗаказа» — пришлите точное имя поля
состояния на форме (как подписано рядом с полем).
