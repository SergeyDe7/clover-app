НАДЁЖНЫЙ СПОСОБ: модуль ОБЪЕКТА документа (не формы)
=====================================================
Факт: вызовы /api/one-c/orders/accepted из 1С до Clover НЕ доходят.
Значит обработчик формы не выполняется. Делаем через модуль объекта.

A. Свойства общего модуля
-------------------------
Конфигуратор → расширение Обмен Clover → Общие модули → Clover_ОбменКлиент
→ свойства (справа или Alt+Enter):
  ☑ Сервер          ← обязательно включить
  ☑ Вызов сервера   ← если есть
  ☑ Клиент (управляемое приложение) — оставить как было
Ctrl+S

B. Модуль объекта ЗаказПокупателя
---------------------------------
1. В расширении: Документы → ЗаказПокупателя
2. Правой кнопкой по ЗаказПокупателя → «Открыть модуль объекта»
   (или «Модуль объекта»). Если пункта нет:
   правой кнопкой → добавить модуль объекта в расширение.
3. В КОНЕЦ модуля объекта вставьте:

&После("ПриЗаписи")
Процедура Clover_ПриЗаписи(Отказ)

	Если Отказ Тогда
		Возврат;
	КонецЕсли;

	Если ЭтотОбъект.ДополнительныеСвойства.Свойство("CloverSkipAcceptedNotify") Тогда
		Возврат;
	КонецЕсли;

	Комментарий = Строка(ЭтотОбъект.Комментарий);
	НомерClover = Clover_ОбменКлиент.ИзвлечьНомерЗаказаCloverИзКомментария(Комментарий);
	Если НомерClover = "" Тогда
		Возврат;
	КонецЕсли;

	СостояниеТекст = "";
	Попытка
		СостояниеТекст = СокрЛП(Строка(ЭтотОбъект.СостояниеЗаказа));
	Исключение
		Попытка
			СостояниеТекст = СокрЛП(Строка(ЭтотОбъект.Состояние));
		Исключение
			СостояниеТекст = "";
		КонецПопытки;
	КонецПопытки;

	Если СостояниеТекст = "" Тогда
		Возврат;
	КонецЕсли;

	Попытка
		Clover_ОбменКлиент.СообщитьОПринятииПоРеквизитам(
			НомерClover,
			Строка(ЭтотОбъект.Номер),
			СостояниеТекст);
	Исключение
		ЗаписьЖурналаРегистрации(
			"Clover.AcceptedNotify",
			УровеньЖурналаРегистрации.Ошибка,,,
			ОписаниеОшибки());
	КонецПопытки;

КонецПроцедуры

4. Ctrl+S
5. Конфигурация → Обновить конфигурацию базы данных → Да
6. Закрыть конфигуратор, открыть 1С:Предприятие

C. Проверка
-----------
1. Новый заказ Clover → в 1С
2. Выбрать состояние → Записать (или Провести и закрыть)
3. В Clover F5 у клиента → «Принят»

Если не сработало: в 1С Журнал регистрации → событие Clover.AcceptedNotify
(там будет текст ошибки HTTP/модуля).
