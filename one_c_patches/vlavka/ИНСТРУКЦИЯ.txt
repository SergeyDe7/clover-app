VLAVKA — рабочая 1С
====================

Полная инструкция: docs/technical/VLAVKA_EXTENSION_INSTALL.md

Кратко:
1. Backup VLAVKA.
2. Модуль целиком: `ПОЛНЫЙ_МОДУЛЬ_VLAVKA.txt` → Clover_ОбменКлиент.
   После вставки верните `ПолучитьКлючОбмена()` из текущей VLAVKA
   (ONEC_VLAVKA_EXCHANGE_API_KEY; shared key с TEST запрещён).
3. Контур: `ПолучитьИмяБазыОбмена()` = "VLAVKA" — и в
   `X-Clover-Database`, и в JSON `body.database` (purchase-prices).
   Не вставляйте `one_c_patches/price_types/ПОЛНЫЙ_МОДУЛЬ_вставить_целиком.txt`
   в VLAVKA as-is: тот файл TEST-only (header и body = TEST).
4. URL: https://clover-spb.ru (API /api/…) или DC :4100.
5. Кнопки «Отправить товары / контрагентов / цены» из VLAVKA — Clover
   принимает базы из текущего allowlist (сейчас VLAVKA-only).
   Последняя выгрузка перезаписывает каталог поиска — для боя только VLAVKA.
6. Выгрузка ≠ матрица клиента: после каталога связать товары и добавить в матрицу.
7. Пилот: в ЛК контур «VLAVKA» → заказ → ACK.
