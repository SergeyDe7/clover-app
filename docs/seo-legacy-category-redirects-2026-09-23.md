# Два устаревших адреса категорий

Локальная подготовка, без публикации. Ветка `codex/seo-legacy-category-redirects`, база `d3233ca`.

## Подтверждённые факты

23.09.2026 прямой HTTP-запрос подтвердил 404 без перенаправления у:

- `/catalog/odnorazovaya-posuda/dlya-sushi-i-lapshi`
- `/catalog/himiya-chistyashchie-sredstva/dlya-okon`

Соответствующие русские страницы отвечают 200, canonical указывает на них же:

- `/ru/catalog/Одноразовая посуда/Для суши и лапши`
- `/ru/catalog/Химия, чистящие средства/Для окон`

Старый `/product/НФ-00002829` уже отвечает 200 с canonical `/ru/product/НФ-00002829`. Название — «Маркер перманентный черный тонкий 1мм Centropen». Его поведение не меняется.

## Изменение

Два точных отсутствующих slug получают 301 на соответствующие опубликованные русские страницы. Query сохраняется. Если русская версия выключена или целевая запись отсутствует в manifest, перенаправления нет. Существующая запись исходного адреса имеет приоритет.

Это исключение для двух неработающих адресов, не массовый переход с unprefixed на prefixed URL. Действующие legacy-маршруты сохраняют 200. Другие языки, sitemap, товары, БД и 1С не изменяются.
