### Подготовка сервера в датацентре

Следуйте [`docs/deploy/CHECKLIST.md`](../deploy/CHECKLIST.md):

1. Windows VM + Node ≥ 22.13 + внутренний IP.
2. `server/.env` из `docs/deploy/server.env.datacenter.example`.
3. Ключ `ONEC_API_KEY`, `ONEC_ALLOW_LOCAL_WITHOUT_KEY=false`.
4. Автозапуск: `tools\Install-CloverAutostart.ps1` (Планировщик, не Windows Service).
5. Firewall: порты 5273 и 4100 в LAN.
6. Приёмка: 2 тестовых заказа с сервера в 1С TEST.

**Установку на сервер агент не выполняет без вашего явного «да».**

## Риски

- Исторические пути/IP в старых отчётах могут быть неактуальны.
- Без `dist` frontend не поднимется — `Start-Clover.ps1` теперь сам делает `npm run build` при отсутствии `dist`.
- Дублирующий `START_CLOVER.bat` сведён к вызову `START_CLOVER_V18.bat`.
- PUT `/api/state/orders` по-прежнему может hard-delete активный заказ omit’ом; soft-delete/`deletedAt` закрыты dedicated endpoints + lock.
