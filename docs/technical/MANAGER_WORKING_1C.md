# Инструкция менеджеру: живые заказы в рабочую 1С

## Важно

- По умолчанию контур передачи — **Тестовая 1С**.
- Для **живых** заказов в селекте нужно явно выбрать **Рабочая 1С**.
- Не переключайте default на сервере: безопасный fallback остаётся TEST.

## Как передать заказ в рабочую 1С

1. Откройте ЛК → **Заказы**.
2. Найдите нужный заказ (статус готов к передаче).
3. В блоке **Контур передачи в 1С** выберите **Рабочая 1С** (не «Тестовая 1С»).
4. Нажмите **Передать в 1С**.
5. Дождитесь статуса обмена / ACK.
6. Сверьте:
   - **Clover ID** заказа в ЛК;
   - **номер документа** в рабочей 1С;
   - запись в журнале Clover (этап передачи и ACK).

## Если сомневаетесь

- Оставьте **Тестовая 1С** — заказ уйдёт только в тестовую базу.
- При ошибке обмена не создавайте повторный документ вручную в 1С: сначала посмотрите статус в Clover и журнал.

## Что НЕ делать без согласования

- Менять настройку сервера «контур по умолчанию».
- Массово отправлять старые заказы в рабочую 1С.
- Передавать один и тот же заказ повторно, если ACK уже есть.
