# Приёмочные заказы в рабочую 1С (2–3 шт.)

Только после явного «да». Контур в UI: **Рабочая 1С**.

## Цель

Подтвердить идемпотентный контур: заказ Clover → очередь → документ в рабочей 1С → ACK с тем же Clover ID и номером документа.

## Перед стартом

- [ ] Backup Clover (`server/data` + `.env`) свежий
- [ ] Расширение в рабочей 1С с `X-Clover-Database: VLAVKA`
- [ ] Health `4.0.4`, менеджер залогинен
- [ ] В селекте выбран **Рабочая 1С** (не TEST)

## Протокол на каждый заказ

| # | Clover ID | № документа 1С | ACK ок | Журнал ок | Примечание |
|---|-----------|----------------|--------|-----------|------------|
| 1 | | | ☐ | ☐ | |
| 2 | | | ☐ | ☐ | |
| 3 | | | ☐ | ☐ | |

Шаги на заказ:

1. Создать небольшой заказ (1–2 позиции).
2. Менеджер: контур **Рабочая 1С** → **Передать в 1С**.
3. В рабочей 1С: появился **новый** документ, номер зафиксировать.
4. В Clover: ACK / статус «принят 1С», Clover ID совпадает.
5. Повторный pull/ACK не создаёт второй документ.
6. Запись в журнале Clover есть.

## Критерий приёмки

Все 2–3 строки заполнены, без дублей документов, ID совпадают. Иначе — стоп, разбор, без mass go-live.
