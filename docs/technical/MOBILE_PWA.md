# Clover на телефоне как приложение (PWA)

## Факт по коду сейчас

| Элемент | Статус |
|---------|--------|
| `public/manifest.webmanifest` | есть, `display: "standalone"` |
| Иконки 192/512 + maskable | есть |
| Service Worker `public/sw.js` | есть, регистрация в `src/main.jsx` |
| Открытие без «рамки браузера» | да, после **«Установить» / «На экран Домой»** |

Это **не** магазинный native APK/IPA, а Progressive Web App: выглядит и запускается как приложение.

## По ОС

| ОС | Как ставится | Условие |
|----|--------------|---------|
| **Android** (Chrome) | «Установить приложение» | нужен **HTTPS** + домен (или localhost для теста) |
| **iPhone / iPad** (Safari) | Поделиться → **На экран «Домой»** | нужен **HTTPS** + домен; без Add to Home Screen откроется Safari |
| **Windows** | «Установить» в Edge/Chrome | HTTPS или localhost |

По IP `http://10.x.x.x` без TLS установка PWA на телефон **обычно не работает** как полноценное приложение.

## Вывод

1. Домен + HTTPS обязательны, если клиенты ставят Clover на телефон «как приложение».  
2. Пока домена нет — клиенты могут пользоваться через браузер по LAN; иконка приложения появится после домена.  
3. Отдельный магазинный App Store / Google Play **не требуется** для текущего плана.
