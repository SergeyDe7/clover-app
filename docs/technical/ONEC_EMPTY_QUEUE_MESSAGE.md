# Короткое сообщение при пустой очереди (1С TEST)

## Что сделано в Clover (backend)

`GET/POST /api/one-c/test-order` при пустой очереди теперь отвечает:

```json
{
  "code": "EMPTY_QUEUE",
  "error": "Нет новых заказов",
  "userMessage": "Нет новых заказов"
}
```

HTTP-код по-прежнему **404** (поведение очереди не менялось).

## Что нужно в расширении 1С

Длинный текст вида  
`Товары переданы, но заказ не создан: {…Модуль(1104)}: Clover вернул HTTP-код 404: {"error":…}`  
формирует **клиентский модуль** расширения (`Clover_ОбменКлиент`), не Clover.

В конфигураторе (база **TEST / КОПИЯ**) найдите обработку ответа получения заказа (около строки ~1104) и для пустой очереди покажите только короткий текст:

```bsl
// Пример логики (имена переменных подставьте свои):
Если КодСостоянияHTTP = 404 Тогда
	// Пустая очередь — не ошибка обмена, а штатная ситуация
	Сообщить("Нет новых заказов");
Иначе
	// Прочие ошибки можно оставить подробными для диагностики
	Сообщить(ПодробныйТекстОшибки);
КонецЕсли;
```

Либо, если разбираете JSON ответа Clover:

```bsl
Если КодОтветаClover = "EMPTY_QUEUE" Тогда
	Сообщить("Нет новых заказов");
КонецЕсли;
```

## Установка в 1С

Обновление расширения / правки BSL в рабочей или TEST 1С — **только после вашего явного «да»**.  
До этого достаточно перезапустить backend Clover, чтобы короткий `error` уже уходил в JSON (часть длинного хвоста станет короче даже без правки 1С).
