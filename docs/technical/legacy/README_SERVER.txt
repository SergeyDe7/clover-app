CLOVER V18.1 — ВАЖНО

Для обновления не запускайте файлы внутри payload.
Используйте только INSTALL_CLOVER_V18.bat в корне пакета.

Рабочие адреса после установки:
- Clover: http://localhost:5273/
- Проверка сервера: http://localhost:4100/api/health

Установщик сам:
- находит единственную рабочую базу Clover;
- останавливает установку, если найдено несколько активных баз;
- проверяет SHA256 всех файлов пакета;
- сохраняет код, server/data, server/uploads, server/.env и прежние зависимости;
- генерирует отсутствующий безопасный JWT без вывода секрета в журнал;
- сохраняет действующие настройки 1С; без API-ключа разрешает callback только с этого компьютера;
- устанавливает зафиксированные версии зависимостей;
- запускает тесты и сборку;
- проверяет сохранность клиентов, заказов, фотографий и настроек;
- при ошибке восстанавливает предыдущую версию и пытается её запустить.

Пароли, SMTP-пароли и ключи обмена не хранятся в документации и не выводятся на экран.
