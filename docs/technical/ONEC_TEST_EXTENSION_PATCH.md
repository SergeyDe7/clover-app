# Правка расширения CloverExchange в 1С TEST (КОПИЯ)

Полная пошаговая инструкция с кнопками и автопатчем файла:

**`one_c_patches/empty_queue_and_comment/ИНСТРУКЦИЯ_КОНФИГУРАТОР.txt`**

Там же:

- `Clover_module.bsl` — готовый модуль (образец №3265, только шт, дата отгрузки, комментарий Clover)
- `APPLY_PATCH.bat` — применить патч к выгруженному модулю
- `Apply-Patch.ps1` — сам скрипт

Готового `.cfe` «одним кликом» нет: модуль `Clover_ОбменКлиент` живёт внутри вашей установленной TEST-базы, его нужно один раз выгрузить (это описано в инструкции, части A–D).
