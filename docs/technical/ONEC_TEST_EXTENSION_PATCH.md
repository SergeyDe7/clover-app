# Правка расширения CloverExchange в 1С TEST (КОПИЯ)

Полная пошаговая инструкция с кнопками и автопатчем файла:

**`one_c_patches/empty_queue_and_comment/ИНСТРУКЦИЯ_КОНФИГУРАТОР.txt`**

Там же:

- `Clover_module.bsl` / `Clover_module_для_вставки.txt` — готовый модуль (образец №3265, только шт, дата отгрузки, комментарий Clover, выгрузка контрагентов, пустое состояние при создании)
- `ИНСТРУКЦИЯ_СТАТУС_ПРИНЯТ.txt` — подписки ПередЗаписью/ПриЗаписи → статус «Принят» у клиента
- `ИНСТРУКЦИЯ_КНОПКА_КОНТРАГЕНТЫ.txt` — добавить в меню Clover кнопку «Отправить контрагентов в Clover - тест»
- `КОМАНДА_КОНТРАГЕНТЫ_ОБРАЗЕЦ.txt` — образец текста обработчика команды
- `ИНСТРУКЦИЯ_ПРИНЯТЬ_ВСЕ.txt` — один клик принимает все заказы из очереди Clover
- `КОМАНДА_ПРИНЯТЬ_ВСЕ_ОБРАЗЕЦ.txt` — опциональный образец кнопки (менять не обязательно)
- `ВСТАВИТЬ_ФУНКЦИЮ_ПРИНЯТЬ_ВСЕ.txt` — памятка: `СоздатьТестовыйЗаказ` сам принимает всю очередь
- `APPLY_PATCH.bat` — применить патч к выгруженному модулю
- `Apply-Patch.ps1` — сам скрипт

Готового `.cfe` «одним кликом» нет: модуль `Clover_ОбменКлиент` и команды меню живут внутри вашей установленной TEST-базы.
