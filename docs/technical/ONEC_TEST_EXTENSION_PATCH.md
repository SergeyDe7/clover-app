# Правка расширения CloverExchange в 1С TEST (КОПИЯ)

Делайте **только** в базе с пометкой КОПИЯ / TEST, не в VLAVKA.

Нужны два изменения в общем модуле `Clover_ОбменКлиент` (сообщение указывает строку ~1104).

## 1. Короткое сообщение при пустой очереди

Найдите место, где при ошибке получения заказа вызывается что-то вроде:

- `Товары переданы, но заказ не создан:` + текст исключения / HTTP

Замените обработку **HTTP 404** (пустая очередь) на:

```bsl
Если КодСостоянияHTTP = 404 Тогда
	Сообщить("Нет новых заказов");
	Возврат;
КонецЕсли;
```

Либо, если читаете JSON ответа Clover:

```bsl
Если КодОтвета = "EMPTY_QUEUE" Или СтрНайти(ТекстОтвета, "Нет новых заказов") > 0 Тогда
	Сообщить("Нет новых заказов");
	Возврат;
КонецЕсли;
```

Не добавляйте в сообщение путь модуля, HTTP-код и сырой JSON.

## 2. Комментарий в «Заказе покупателя»

Clover уже отдаёт в JSON поле:

```text
comment: "Заказ Clover № CL-…"
```

В расширении **не дописывайте** в комментарий документа:

- `[CLOVER:…]`
- `Адрес доставки: …`
- прочие служебные строки

Оставьте в поле комментария документа **только** значение `comment` из ответа Clover  
(формат: `Заказ Clover № ` + номер заказа).

UUID Clover по-прежнему приходит в поле `order.id` — его можно писать в отдельный реквизит/свойство, если нужно для ACK, но **не в комментарий**.

Адрес берите из `order.address` / поля адреса документа, не из комментария.

## Как открыть модуль

1. Конфигуратор → конфигурация базы **TEST/КОПИЯ**.
2. Расширение **CloverExchange**.
3. Общие модули → `Clover_ОбменКлиент`.
4. Правка → сохранить → обновить конфигурацию БД.
5. Перезапустить 1С (тонкий/толстый клиент).

## Проверка

1. Очередь пустая → кнопка получения заказа → сообщение ровно: **Нет новых заказов**.
2. Новый заказ из Clover → в комментарии документа только: **Заказ Clover № CL-…** (без UUID и адреса).

Если не найдёте строку ~1104 — пришлите скрин модуля из конфигуратора, подскажу точное место.
