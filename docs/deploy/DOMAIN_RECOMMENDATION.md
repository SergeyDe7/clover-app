# Домен для Clover — рекомендация

## Лучший вариант сейчас

Купите **один короткий домен в зоне `.ru`** (или `.рф`, если нужен кириллический бренд).

Предпочтительные имена (проверьте свободу у регистратора):

1. `clover-zakaz.ru` — понятно клиенту («заказы Clover»)
2. `myclover.ru` — коротко для PWA на телефоне
3. `cloverapp.ru` — универсально

Регистраторы с простой DNS для датацентра: **REG.RU**, **Timeweb**, **Beget**.

## Как настроить (после покупки)

1. Пока сервер в ДЦ не готов — домен можно держать на «заглушке» у регистратора.
2. Когда будет IP сервера: DNS **A-запись** `@` → IP; при желании `www` → тот же IP или CNAME на `@`.
3. На сервере: HTTPS (Caddy / IIS + Let’s Encrypt) → см. `docs/deploy/AFTER_DOMAIN.md`.
4. В `server/.env`: `APP_PUBLIC_URL` / `CLOVER_PUBLIC_URL` / Passkey = `https://ваш-домен.ru`.

## Чего избегать

- Бесплатные кривые поддомены без нормального HTTPS — PWA на iPhone часто не ставится.
- Сразу несколько доменов — один основной достаточно.
- Публиковать Clover в интернет на голый HTTP без TLS.

## Зачем домен обязателен для «как приложение» на телефоне

Установка PWA (иконка на рабочий стол, без строки браузера) на **Android/iOS** в реальной сети practically требует **HTTPS на своём домене**.  
На `localhost` это работает только для тестов на том же компьютере.
