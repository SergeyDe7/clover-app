# Откат установки на сервере

1. Остановить Clover: `STOP_CLOVER_V18.bat` или снять задачу автозапуска.
2. Восстановить последний backup из папки резервных копий (код + `server/data` + `server/.env`).
3. Запустить снова и проверить `http://127.0.0.1:4100/api/health`.
4. Если сломалось расширение 1С — вернуть предыдущий `.cfe` из backup и загрузить в 1С TEST.

Не удаляйте единственную копию sqlite до проверки, что backup открывается.
