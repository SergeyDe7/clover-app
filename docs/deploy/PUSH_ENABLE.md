# Включение Web Push и цифры на иконке

Код push в Clover уже есть. Без шагов ниже уведомления **не уходят** на телефон.

## Что получите

| Канал | Что видно пользователю |
|-------|-------------------------|
| Push | Всплывающее уведомление ОС (Android / Windows / iOS PWA) |
| Badge | Цифра на иконке установленного PWA (лучше всего Android и Windows) |
| Колокольчик | Непрочитанные внутри кабинета менеджера (уже работает без VAPID) |

iPhone: push только после **«На экран Домой»** (iOS 16.4+). Цифра на иконке на iOS — ненадёжна; основной сигнал — сам push.

## Чеклист включения (без ДЦ / без production без «да»)

### 1. Домен и HTTPS

1. Домен указывает на сервер Clover.
2. HTTPS работает (Caddy / nginx / IIS ARR + Let's Encrypt).
3. В `server/.env`:
   - `APP_PUBLIC_URL=https://ваш-домен`
   - `CLOVER_PUBLIC_URL=https://ваш-домен`
   - `PASSKEY_RP_ID=ваш-домен` (без `https://`)
   - `PASSKEY_ORIGIN=https://ваш-домен`

Подробнее: [AFTER_DOMAIN.md](./AFTER_DOMAIN.md).

### 2. VAPID-ключи

На машине с установленным `server` (из папки `server`):

```bash
npx --yes web-push generate-vapid-keys
```

В `server/.env` добавить вывод:

```env
VAPID_SUBJECT=mailto:ваш@email.ru
VAPID_PUBLIC_KEY=...
VAPID_PRIVATE_KEY=...
```

Перезапустить backend. Проверка: `GET /api/push/status` → `"enabled": true`.

### 3. Подписка на устройстве

1. Открыть Clover по **HTTPS** (не по голому IP).
2. Android: установить PWA («Установить приложение»). iPhone: Safari → Поделиться → **На экран «Домой»**.
3. Войти менеджером (или клиентом).
4. Настройки → **Включить уведомления** → разрешить в системном диалоге.

### 4. Настройки менеджера

В кабинете менеджера / админа:

- канал **Push на устройства менеджера** — включён (по умолчанию да);
- при необходимости отдельно: email / Telegram.

### 5. Проверка

1. Создать тестовый заказ клиентом (или админ-тест уведомлений, если доступен).
2. На телефоне менеджера: всплывающий push.
3. На Android/Windows PWA: цифра на иконке ≈ число непрочитанных.
4. Открыть уведомления в кабинете / «Прочитано» → цифра уменьшается или сбрасывается.

## Ограничения

- По `http://IP` в LAN полноценный push/PWA обычно **не** включается.
- Секреты VAPID не коммитить в Git.
- Включение на сервере ДЦ / production — только после явного подтверждения.

## Откат

Удалить или очистить `VAPID_*` в `.env` и перезапустить backend → `enabled: false`, push перестаёт отправляться. Код badge безвреден, если API ОС нет.
