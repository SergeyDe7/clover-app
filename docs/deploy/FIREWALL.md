# Firewall / порты Clover

## Минимально для LAN без домена

| Порт | Назначение | Кто ходит |
|------|------------|-----------|
| TCP 5273 | Frontend / PWA | ПК пользователей |
| TCP 4100 | Backend API + `/api/one-c` | ПК пользователей, 1С TEST |
| TCP 3389 | RDP (если нужен) | только админ, по VPN лучше |

## Правила

1. Не публиковать 4100/5273 в интернет без reverse-proxy и HTTPS.
2. Ограничить источник 1С IP-адресом сервера 1С, если firewall это умеет.
3. После появления домена: снаружи только 443 → proxy → 5273/4100; прямые порты закрыть с WAN.

## Проверка

С другого ПК в сети:

```text
http://SERVER_IP:4100/api/health
http://SERVER_IP:5273/
```
