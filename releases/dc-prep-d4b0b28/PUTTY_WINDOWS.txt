================================================================================
КАК УСТАНОВИТЬ И НАСТРОИТЬ PuTTY НА WINDOWS
Для выката Clover на Linux в ДЦ (SSH)
Дата: 2026-08-02
================================================================================

Зачем PuTTY
-----------
Через браузер на сервер «для обновления» не заходят.
PuTTY — маленькая программа: чёрное окно, куда вставляют команды выката.
Сайт Clover потом открываете в Chrome/Edge: http://IP:5273/


--------------------------------------------------------------------------------
1. Скачать
--------------------------------------------------------------------------------
1) Откройте в браузере официальный сайт:
     https://www.chiark.greenend.org.uk/~sgtatham/putty/latest.html
2) В разделе «Package files» для 64-bit Windows скачайте:
     putty-64bit-0.xx-installer.msi
   (или «MSI» / «64-bit» installer — название с версией).
3) Не качайте со случайных «скачать бесплатно» сайтов.


--------------------------------------------------------------------------------
2. Установить
--------------------------------------------------------------------------------
1) Запустите скачанный .msi
2) Next → I accept → Next → Install
3) Готово (Finish).
4) В меню Пуск появится: PuTTY


--------------------------------------------------------------------------------
3. Первый вход на сервер (когда Андрей даст данные)
--------------------------------------------------------------------------------
Вам понадобятся от Андрея / ДЦ:
  • Host Name (IP)     например 10.0.0.50
  • Port               обычно 22
  • Username (логин)   например clover или ваш логин
  • Password (пароль)  или файл ключа .ppk

Шаги:
1) Пуск → PuTTY
2) В окне Configuration:
     Host Name (or IP address):  <IP от Андрея>
     Port: 22
     Connection type: SSH  (должно быть выбрано)
3) Слева: Connection → Data
     Auto-login username:  <логин от Андрея>
   (можно пропустить и ввести логин потом)
4) Вернитесь в Session (сверху слева).
5) В Saved Sessions введите имя, например:  clover-dc
6) Нажмите Save — чтобы не вводить IP каждый раз.
7) Нажмите Open.
8) Если спросят про ключ сервера («PuTTY Security Alert») —
   при первом подключении обычно Yes
   (IP должен быть тот, что дал Андрей).
9) В чёрном окне:
     login as:  <логин>   (если не указали Auto-login)
     password:  <пароль>  (при вводе символы НЕ видны — так и должно быть)
10) Успех: строка вида
      user@clover-test:~$
    или
      clover@clover-test:~$


--------------------------------------------------------------------------------
4. Вставить команды выката
--------------------------------------------------------------------------------
1) Откройте шпаргалку: DEPLOY_TO_DC.txt (из пакета / zip).
2) В PuTTY: ПКМ по заголовку окна → ничего копировать из Word с «красивыми»
   кавычками. Лучше копировать из блокнота.
3) Вставка в PuTTY: просто правый клик мыши в чёрном окне
   (Ctrl+V часто НЕ работает).
4) После каждой команды — Enter.
5) Когда закончили выкат:
     curl -sS http://127.0.0.1:4100/api/health
6) В браузере на моноблоке:
     http://<IP_сервера>:5273/


--------------------------------------------------------------------------------
5. Выход
--------------------------------------------------------------------------------
Введите:  exit
или закройте окно PuTTY.


--------------------------------------------------------------------------------
Частые проблемы
--------------------------------------------------------------------------------
• «Network error: Connection timed out»
  — нет сети/VPN до ДЦ, неверный IP, порт 22 закрыт. Пишите Андрею.

• «Access denied» / пароль не подходит
  — раскладка EN, Caps Lock; попросите новый пароль.

• Пароль «не печатается»
  — нормально для SSH.

• Хотите без пароля каждый раз
  — Андрей может выдать ключ .ppk:
    Connection → SSH → Auth → Credentials → Browse (файл .ppk)


--------------------------------------------------------------------------------
Не путать
--------------------------------------------------------------------------------
PuTTY / SSH     = обновить программу на сервере
Браузер         = пользоваться Clover
FileZilla       = по желанию смотреть файлы (не обязателен для выката)
RDP             = не нужен для Linux Clover
